# Karya Digital Studio - Business Website Demo

# Deskripsi

Proyek latihan mandiri berupa website profil bisnis sederhana untuk mendemonstrasikan kemampuan dasar web development.

# Teknologi

- HTML5
- CSS3
- CSS Grid
- Responsive Web Design

# Fitur

- Navigasi ke bagian halaman
- Hero section
- Daftar layanan
- Bagian tentang bisnis
- Tombol kontak melalui email
- Layout responsif untuk layar desktop dan seluler

# Cara Menjalankan

1. Unduh atau salin folder proyek.
2. Buka file `index.html` menggunakan browser modern.

# Status Proyek

Personal learning project - bukan proyek klien.

# Pengembangan Berikutnya

- Menambahkan JavaScript untuk interaksi yang relevan.
- Meningkatkan aksesibilitas.
- Menyiapkan deployment agar website dapat diakses melalui URL publik.
